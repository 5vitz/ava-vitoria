# 📋 Controle de Tarefas Pendentes (TASKS)

Este diretório contém os arquivos de especificação de tarefas que ainda precisam ser desenvolvidas ou integradas no e-commerce **AVA Vitória**.

## 🚀 Como Funciona o Fluxo:
1.  **Ideação/Planejamento:** Uma nova tarefa é criada aqui na pasta `docs/TASKS/` com a numeração sequencial (ex: `001-nome-da-tarefa.md`).
2.  **Desenvolvimento:** O Maestro Lincoln e o Genera trabalham na execução da tarefa seguindo o prompt gerado.
3.  **Conclusão e Homologação:** Assim que a tarefa for concluída e aprovada manualmente pelo Genera, o arquivo correspondente é movido para a pasta **`docs/DONE/`** (Concluídas), limpando o backlog ativo.
